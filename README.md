<h2>✨ Fitur Utama</h2>
<ul>
  <li><b>Sistem Booking Jadwal:</b> Pelanggan dapat memilih waktu dan layanan pangkas rambut yang tersedia.</li>
  <li><b>Manajemen Data Terpusat:</b> Menggunakan database SQLite yang ringan dan cepat untuk menyimpan data reservasi.</li>
  <li><b>Antarmuka Responsif:</b> Desain UI yang ramah pengguna, baik saat diakses melalui perangkat <i>mobile</i> maupun <i>desktop</i>.</li>
  <li><b>Siap Deployment:</b> Konfigurasi yang mudah untuk di-<i>deploy</i> ke layanan <i>cloud hosting</i>.</li>
</ul>

<h2>🛠️ Tech Stack</h2>
<ul>
  <li><b>Backend:</b> Python, Flask</li>
  <li><b>Database:</b> SQLite</li>
  <li><b>Frontend:</b> HTML, CSS, JavaScript</li>
</ul>

<h2>🚀 Cara Instalasi & Menjalankan di Local</h2>
<p>Ikuti langkah-langkah berikut untuk menjalankan project ini di komputer lokal:</p>

<ol>
  <li>
    <b>Clone repository ini</b>
    <pre><code>git clone https://github.com/bajiff/baji-barbershop.git
cd baji-barbershop</code></pre>
  </li>
  <li>
    <b>Buat dan aktifkan Virtual Environment</b>
    <p><i>Linux/macOS:</i></p>
    <pre><code>python3 -m venv venv
source venv/bin/activate</code></pre>
    <p><i>Windows:</i></p>
    <pre><code>python -m venv venv
venv\Scripts\activate</code></pre>
  </li>
  <li>
    <b>Install Dependencies</b>
    <pre><code>pip install -r requirements.txt</code></pre>
  </li>
  <li>
    <b>Inisialisasi Database & Jalankan Aplikasi</b>
    <pre><code>flask run</code></pre>
    <p>Aplikasi akan berjalan di <code>http://127.0.0.1:5000/</code>.</p>
  </li>
</ol>
